# Terms

- Background refresh: timer-driven or subscription-driven work that runs without direct user input.
- Global render: a TUI render requested through `tui.requestRender()`.
- Visible state: values that affect lines returned by a component's `render()` method.
- Usage totals: stored `cost` and `tokens` values for one root session family.
- Elapsed refresh cadence: interval between visible elapsed-time updates for an active selected subagent.
