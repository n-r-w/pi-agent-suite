# Terms

- Pi 0.99.0 migration: The package transition from Pi 0.87.1 to Pi 0.99.0 without enabling new Pi features.
- Host-provided packages: `pi-agent-core`, `pi-ai`, `pi-coding-agent`, and `pi-tui` under `@earendil-works`.
- ExtensionToolContext: Pi's tool execution context, which extends `ExtensionContext` with `tools` and `executeTool`.
- Tool exposure: Pi's classification of how a model or another tool can reach a registered tool. The fixture value `direct` represents an ordinary active tool.
