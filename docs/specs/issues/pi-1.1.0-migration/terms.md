# Terms

- Project functionality: the capabilities of the project's extensions and their interactions.
- Functional disruption: loss of a capability or an unintended change in extension behavior after the Pi update.
- Native MCP tool: an MCP server tool or resource helper registered by Pi's built-in MCP extension.
- MCP wrapper tool: an MCP server tool registered by the project's `mcp-wrapper` extension.
- Image type: the MIME type identifying the format of the encoded image data.
