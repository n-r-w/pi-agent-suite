# Terms

- root manifest: The repository-level `package.json` that declares Pi packages as development dependencies.
- published manifest: `pi-package/package.json`, which declares the Pi host contract as peer dependencies.
- Pi packages: `@earendil-works/pi-agent-core`, `@earendil-works/pi-ai`, `@earendil-works/pi-coding-agent`, and `@earendil-works/pi-tui`.
- dependency synchronization: Updating all repository declarations and lock files for the Pi packages to one exact version.
