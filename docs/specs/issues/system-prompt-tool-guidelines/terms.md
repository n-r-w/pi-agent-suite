# Terms

- Per-tool guidelines: shared guidance supplied in Pi's `options.toolGuidelines`, keyed by tool name.
- Global guidelines: contributions supplied in Pi's `options.promptGuidelines`, independent of tool selection.
- Active tools: tools returned by `pi.getActiveTools()` after runtime policy reconciliation.
- Hidden tools: tools listed in Pi's `options.hiddenTools`.
- Normalized guideline: a contribution with surrounding whitespace removed.
- Individual tool descriptions: descriptions attached to tool definitions in the provider tool payload.
