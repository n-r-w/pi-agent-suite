Exit the active workflow at any stage. Supply a nonempty free-text basis stating the facts that justify leaving it. Finish the work of a final stage before exiting. Exit removes the top workflow. When it owns a pending transition, supply boolean `allow`: true enters the parent's requested target stage with its effective settings and entry triggers in this call; false resumes the unchanged parent stage without entry triggers. Permission can be given or refused at any stage of the check. Missing permission rejects a pending exit. An ordinary workflow ignores a supplied boolean `allow`; when its parent waits, continue the parent's same stage in this agent run with its effective settings and no entry triggers. When no parent remains, exit restores the original root snapshot and leaves no workflow. Settlement of an agent run does not exit a workflow.
